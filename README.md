## 🎯 How to Use

1. **Clone the repository**
```bash
git clone https://github.com/BodkeSachin7979/SQL_DATA_ANALYSIS.git
cd SQL_DATA_ANALYSIS
```
2. Navigate to a project folder (e.g. 1Retail_sales_analysis)

3. Open SQL scripts or project README for instructions

5. Execute scripts in your preferred database (PostgreSQL / MySQL / SQLite)

6. Explore results, insights, and analysis outputs
   
⚠️ Note: Projects are independent. Check prerequisites like database schema or sample datasets before running.
